# 代码评审意见顾问

把评审发现转写成"合适的代码意见"，并对草稿做语气把关。可执行实现在 `agents/code-review-advisor/`。

## 工作流

1. **结构化润色**（输入是发现列表 JSON 时）：
   ```bash
   python agents/code-review-advisor/src/review_advisor_agent/cli.py '<JSON 数组>' --offline
   ```
   得到按严重度排序、问题-影响-建议-依据结构、开场收尾礼仪的意见文本 + 作者回复三模板（接受/部分接受/说明背景）。
2. **语气终检**（输入是草稿文本时）：检查攻击性评价、人身指向（"你又错了"）、绝对化（"必须"）、反问质问、翻旧账五类红线，逐条给替换建议；发出评论前必须通过。
3. **意见质量标准**：对事不对人 / 可执行（带改法）/ 有依据（引规则）/ 分级明确（[阻断][应修][建议][nit]）/ 留余地（不确定用提问式）。

## 措辞速查

| severity | 前缀 | 语义 |
|----------|------|------|
| critical | **[阻断]** | 安全/正确性，合入前必须解决 |
| high | **[应修]** | 合入前应修，可拆 follow-up |
| medium | **[建议]** | 不阻塞，建议本轮处理 |
| low | **[nit]** | 明示可改可不改，避免刷屏 |

## 约束

- 不新增技术判断（技术内容以上游发现为准，只负责表达）；不改变阻断语义。
- 详版礼仪与模板见 `agents/code-review-advisor/knowledge/review-etiquette.md`。
